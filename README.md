# build-chinese-ebook-from-scans

已有俄文/外文扫描版 PDF 和每页中文译文（zh_pages/pg_NNN.txt）时，用 reportlab + PyMuPDF 重排成一本嵌入中文字体、可阅读的电子书 PDF。

## Install

```bash
git clone https://github.com/longhai-lanxin/build-chinese-ebook-from-scans.git ~/.workbuddy/skills/build-chinese-ebook-from-scans
```

Compatible with any agent that reads `SKILL.md` frontmatter (WorkBuddy / CodeBuddy / Claude-style skills).
